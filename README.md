# Modbus Bridge для Home Assistant

Аддон читает Modbus RTU датчики (температура/влажность) через USB-RS485 
и публикует данные в MQTT с автоматическим созданием сенсоров в HA.

**Статус:** Beta v1.0

## Возможности

- Опрос нескольких датчиков по RS-485 (Modbus RTU)
- Поддержка Holding и Input регистров
- Веб-интерфейс для управления датчиками (добавление, редактирование, удаление)
- Настройка порта, скорости, интервала опроса через UI
- MQTT Discovery — сенсоры создаются в HA автоматически
- Сохранение конфигурации между перезапусками

## Установка

1. В Home Assistant: **Настройки → Аддоны → Магазин аддонов**
2. Три точки в правом верхнем углу → **Репозитории**
3. Добавьте URL: `https://github.com/vist5/modbus_addon`
4. Найдите аддон **Modbus Bridge** → **Установить**
5. Настройте опции (COM-порт, MQTT) → **Сохранить**
6. **Запустить**

## Использование

Откройте панель **Modbus Bridge** в боковом меню HA.

- **Список датчиков** — текущие настроенные датчики
- **Добавить датчик** — форма добавления
- **Настройка Modbus** — параметры порта

## Известные ограничения (Beta v1.0)

- При потере связи с COM-портом требуется перезапуск аддона
- Нет автоматического отключения неотвечающих датчиков
- Требуется перезапуск при изменении параметров порта (baudrate и т.д.)

## Планы (v1.1+)

- Автоматическое переподключение при потере связи
- Автоотключение неотвечающих датчиков
- Дополнительные типы сенсоров
